Day-1) Simple greeting app — ask name & age, print a personalized message

question1
Concepts used: print(), input(), variables, string formatting (f-strings)
Problem Statement
Write a Python program that:
Asks the user to enter their name.
Asks the user to enter their age.
Asks the user to enter their favorite hobby.
Prints a personalized greeting message using all three inputs.
Example Run:
Enter your name: Arun
Enter your age: 22
Enter your favorite hobby: cricket

Hello Arun! 👋
You are 22 years old.
Wow, cricket is awesome! Keep enjoying it.
